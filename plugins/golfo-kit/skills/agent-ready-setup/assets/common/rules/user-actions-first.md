# User Actions First

When a long task is finished, or you are blocked and need the user to do something, start your response with what you need from them.

- Put the list at the very top of the response, before any summary or detail. Number it, with one action per item.
- Make each item self-contained: what the user must do, where, and what to send back when done. For example: "Sign in to Stripe, export the September refunds CSV, and put it in `inbox/`."
- Order the items by how much they block you: the action that blocks the most goes first.
- If you need nothing from the user, say so in one line at the top instead of the list.
- Ask only for what you cannot do yourself, as `browser-before-user-questions.md` defines. Items that report unverified work, as `verify-changes.md` requires, belong in this list only when they need a user action.
